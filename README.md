# Research Assistant AI

An agentic AI research assistant built with LangGraph, FastAPI, and Streamlit.

## Features

- Agentic workflow using LangGraph
- Academic paper search (arXiv)
- Web search (Tavily)
- Research report generation
- FastAPI backend
- Streamlit frontend

## Tech Stack

- Python
- FastAPI
- Streamlit
- LangGraph
- LangChain
- Groq
- FAISS
- uv
